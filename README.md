# Adhd Brainstorm Circle

可以建立一个网站吗，上面主要是为了记录adhd的1，分为三个界面，第一个是adhd的困扰，第二个是对应该困扰可以提出的解决办法，第三个是adhd们相互鼓励。2，界面分完之后可以有个添加的项目，就类似于你可以选择添加什么困扰，什么解决办法，什么鼓励的内容。3，这些东西都有个可以设计优先级的东西，就是一到五星自行设计优先级。4，设计一个网页，作为第四个界面，里面可放置一些学术论文的地方，然后还有个地方写下自己的对这个论文的感悟
